# TALOS True Vector Assets

These files are rebuilt as real SVG paths from the approved TALOS silhouette.
They contain no embedded raster images, masks, gradients, or background rectangles.

- `-bronze.svg` uses one flat brand color: `#B08C65`.
- `-white.svg` uses solid white: `#FFFFFF`.
- `-black.svg` uses solid black: `#000000`.

Use the horizontal logo in application headers, the primary logo for square
brand placements, the wordmark when the sentinel is already visible, and the
mark or favicon files for compact UI and browser icons.
