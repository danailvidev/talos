# TALOS Transparent SVG Assets

Every asset has a transparent background and three finishes:

- `-bronze.svg` preserves the approved bronze and ivory artwork.
- `-white.svg` is a single-color version for dark surfaces.
- `-black.svg` is a single-color version for light surfaces and print.

Use `talos-logo-horizontal-*` in wide application headers, `talos-logo-primary-*` for square brand placements, `talos-wordmark-*` where the sentinel is already present, and `talos-mark-*` or `favicon-*` for compact UI and browser icons.

The approved source artwork was generated as a raster image. These SVG files preserve it through embedded transparent image masks; they are SVG assets with scalable canvases, but they are not hand-redrawn geometric vectors. For very large signage or fabrication, commission a manual vector redraw from the approved mark.
